# Resources

Files the owner sends for the book. Extracted text goes in `resources/text/` (not committed; remake with
`pdftotext -layout`, and for .docx read `word/document.xml`). All files below have a real text layer (no OCR needed).

## Textbooks and lecture notes (main source for chapter notes)
| File | What it is | Use for |
|---|---|---|
| `Pediatric Summeries By DR.Asma Hadida - Reduced ….pdf` | Dr. Asma Hadida's pediatric summaries (2015–16), 533 pages, by system (starts with CVS: fetal circulation, CHD …). | Main teaching-hospital notes for every system chapter. |
| `Aljazeera pediatrics.pdf` | University of Gezira pediatrics lecture notes, 298 pages: history taking, anaemia, genetics, PEM, gastroenteritis, JRA, thyroid, CHD, rheumatic fever, CHF, bleeding disorders, PSGN, UTI, malaria, meningitis, diphtheria, encephalitis, congenital anomalies, neonatal jaundice, RDS, HIE, hepatitis … | Sudanese lecture notes for most topics. |
| `Kibreet Notes in Pediatrics.pdf` | Kibreet notes part A, 69 pages: neonatology, malnutrition, neuropediatrics, haematology, rheumatology, exanthemas, immunization. | Concise exam-focused notes. |
| `Kibreet Pediatric B.pdf` | Kibreet notes part B, 49 pages: respiratory, endocrine (DM, thyroid), short/tall stature, puberty, oncology, renal, genetics. | Concise exam-focused notes. |
| `Illustrated baby nelson general pediatrics.pdf` | Illustrated Baby Nelson, general pediatrics, 309 pages. | Standard reference, figures and tables for checking facts. |
| `Illustrated baby nelson special pediatrics.pdf` | Illustrated Baby Nelson, special (systemic) pediatrics, 384 pages. | Standard reference for system chapters. |
| `Case files pediatrics 5th edition.pdf` | Case Files Pediatrics, 5th ed., 550 pages: clinical cases with discussion and review questions. | Case approach, Try-it and QBank items. |
