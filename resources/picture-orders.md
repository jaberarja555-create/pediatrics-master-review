# Picture orders (image prompts for Gemini)

Send each prompt as it is. Save the result with the file name given, and send the files (or a Word file with the
name under each picture). Rules for every picture: realistic, no text, labels, arrows or watermark in the image,
plain light background, clinic setting, Sudanese / East African mother and child, medical-textbook quality.
